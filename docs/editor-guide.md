# Mario Level Editor — 操作手册

## 启动方式

```bash
cargo run --bin editor        # 启动编辑器
cargo run --bin mario-platformer  # 启动游戏（编辑器保存后即时生效）
```

编辑器是独立 exe，与游戏并行运行。编辑保存后切到游戏窗口即可看到改动。

## 工具表

| 按键 | 工具 | 放置方式 | 渲染颜色 |
|------|------|---------|---------|
| `1` | Platform | 点击两角拉矩形 | 绿(地面) / 棕(浮台) |
| `2` | Spike | 单击放置 | 红色三角 |
| `3` | Coin | 单击放置 | 金色圆 |
| `4` | Q-Block | 单击放置 | 橙色 + ? |
| `5` | Brick | 单击放置 | 棕色方块 |
| `6` | Enemy | 点击两个巡逻端点 | 棕色方块 + 巡逻线 |
| `7` | DartEnemy | 单击放置 | 灰方块 + 红眼 |
| `8` | OscFire | 点 top_y → 点 bottom_y | 橙火球 + 竖线 |
| `9` | Checkpoint | 单击放置 | 灰色杆 + 绿旗 |
| `0` | Flagpole | 单击放置 | 灰杆 + 绿旗 |
| `P` | Spawn | 单击放置 | 小马里奥 + START |
| `Del` | Eraser | 单击删除实体 | — |

工具栏按钮可以**鼠标悬停高亮**，**左键点击**选择工具。

## 视图操作

| 操作 | 按键 |
|------|------|
| 平移 | 方向键 或 鼠标中键拖拽 |
| 缩放 | `+` / `-` 或 鼠标滚轮 |
| 网格吸附 | `G` 切换 (默认开) |
| 取消绘制 | `Esc` |

## 文件操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 加载关卡1-8 | `F1` ~ `F8` | 从 `assets/levels/{n}.json` 读取 |
| 新建关卡 | `Ctrl+N` | 空白模板，自动分配下一个可用编号 |
| 快速保存 | `Ctrl+S` | 保存到当前关卡文件 |
| 另存为 | `Ctrl+Shift+S` | 输入任意路径后按 Enter，Esc 取消 |

**新建关卡流程：**
1. `Ctrl+N` → 获得空白模板（自动编号如 level 5）
2. 编辑地图
3. `Ctrl+S` → 保存为 `assets/levels/5.json`
4. 游戏中即可在选关画面看到第5关

**另存为流程：**
1. `Ctrl+Shift+S` → 底部出现输入框
2. 输入路径如 `assets/levels/my_boss.json` 或绝对路径
3. `Enter` 确认保存，`Esc` 取消

## 关卡格式

编辑器生成标准 JSON，与游戏完全兼容：

```json
{
  "bounds": { "min_x": 0, "max_x": 3600, "min_y": 0, "kill_y": 2500 },
  "platforms": [ ... ],
  "spikes": [ ... ],
  "coins": [ ... ],
  "question_blocks": [ ... ],
  "bricks": [ ... ],
  "enemies": [ ... ],
  "dart_enemies": [ ... ],
  "osc_fireballs": [ ... ],
  "checkpoints": [ ... ],
  "flagpole": { "x": 3500, "y": 560 },
  "player_spawn": { "x": 100, "y": 600 },
  "parallax": [0.1, 0.3, 0.6]
}
```

## 游戏端对应

- 选关画面支持 **8 关**（2行×4列），方向键上下左右导航
- 游戏启动时 **优先读取文件系统** 的 `assets/levels/{n}.json`
- 编辑器 `Ctrl+S` 保存后，游戏无需重启或重新编译
- 第5-8关在选关画面显示为 "CUSTOM 5" ~ "CUSTOM 8"

## 小技巧

- **平台**拉矩形时，第二个点击决定宽高（最小 16×16）
- **敌人**巡逻线：第一个点是位置和 waypoint_a，第二个点是 waypoint_b
- **摆动火球**：第一个点是 x 坐标和 top_y，第二个点是 bottom_y
- **出生点**默认 (100, 600)，放在平台上才能正常开始
- 脏标记 `*` 显示在右上角关卡号旁，提示有未保存修改
- 坐标实时显示在鼠标旁，方便精确定位
