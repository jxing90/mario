## 2a. 测试范围（Test Scope）

项目规模：**小型 (13 features)** — 完整回归 + 每共享边界集成 + 1-2 冒烟测试 + 每角色 E2E + NFR 抽查 + 3-5 charter

| 类别 | 适用 | 跳过条件 | 适用判断 |
|------|------|---------|---------|
| 回归 | **适用** | 永不 | 13/13 特性已通过逐特性 ST |
| 集成 | **适用** | — | 11 个 IAPI 契约跨 10 个核心特性，共享数据/状态/API 边界 |
| E2E 场景 | **适用** | — | SRS 含多步用户工作流 (game start→play→collect→power-up→die→respawn→win) |
| 性能 | **适用** | — | NFR-001 (60fps 帧率)、NFR-002 (多分辨率) |
| 安全 | **适用 (轻量)** | — | 处理键盘输入；离线应用无认证/网络，以输入校验审计为主 |
| 兼容性 | **适用 (平台)** | — | CON-003 指定 Windows 桌面平台；NFR-002 多分辨率 |
| 探索性 | **适用** | 永不 | 3-5 个 charter 覆盖主要特性区域 |

## 2d. 风险驱动的优先排序

1. **关键路径** — 核心玩家工作流: Playing→Movement→Collision→Death→Respawn→HUD→Win (F01-F09)
2. **集成边界** — IAPI-004 (Physics dispatch), IAPI-007→010 (Camera chain), IAPI-009 (Player→HUD), IAPI-011 (Display config)
3. **NFR 阈值** — NFR-001 帧率实测、NFR-002 分辨率一致性
4. **边界情况** — Game Over→Reset 状态完整性、重生金币复位、全屏切换
5. **兼容性** — Windows .exe 运行验证、多分辨率渲染
